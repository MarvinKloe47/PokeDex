# 🧩 Pokédex App

A modern, responsive Pokédex built with **HTML, CSS, and JavaScript**, using real-time data from the Pokémon API.

---

## 🚀 Features

* 🔎 Search Pokémon by name
* 📦 Dynamic Pokémon card rendering
* 🧠 Detailed modal with stats & info
* 📱 Responsive design (mobile + ultra-wide support)
* ❌ User feedback if no Pokémon is found
* 🎨 Clean UI with modular structure

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)
* Pokémon REST API
